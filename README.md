## What This Does

A four-stage deterministic pipeline that runs after an AI generates a legal response:

```
AI Response
    │
    ├─ Stage 0: Section Normalizer   →  IPC/CrPC/IEA  →  BNS/BNSS/BSA
    ├─ Stage 1: Citation Extractor   →  finds all 6 Indian citation formats
    ├─ Stage 2: Hallucination Filter →  catches impossible citations instantly
    ├─ Stage 3: IK API Verifier      →  confirms citations against 30M+ docs
    └─ Stage 4: Annotator            →  injects ✅ ⚠️ ❌ badges + report

Output: annotated text + verification report shown side-by-side with raw AI output
```

---

## Why This Exists

In 2023, lawyers filed a court brief in Mata v. Avianca with 6 completely fabricated cases generated by ChatGPT. Every citation was hallucinated. The lawyers were fined $5,000 each.

In India, the problem compounds — the entire criminal code changed on July 1, 2024. The IPC (1860) became the BNS (2023). The CrPC became the BNSS. AI models still cite the old repealed sections because their training data predates the change.

This engine prevents both failures.

## Setup Guide

### Step 1 — Clone the repository

```bash
git clone https://github.com/Phanivighnesh/brahmo-citation-safety.git
cd brahmo-citation-safety
```

### Step 2 — Install Python dependencies

```bash
pip install -r requirements.txt
```

### Step 3 — Install frontend dependencies

```bash
cd frontend
npm install
cd ..
```

### Step 4 — Configure environment variables

```bash
cp .env.example .env
```

Open `.env` in any text editor and fill in your keys:

```env
# Gemini API key — get free key at https://aistudio.google.com
GEMINI_API_KEY=your_gemini_key_here

# Indian Kanoon API key — free ₹500 credit at https://api.indiankanoon.org/signup/
INDIAN_KANOON_API_KEY=your_ik_key_here

# Gemini model — run: python check_models.py to find your available models
GEMINI_MODEL=models/gemini-2.5-flash
```

> ⚠️ Never commit your `.env` file. It is already in `.gitignore`.

### Step 5 — Find your available Gemini model


This lists every Gemini model your API key can access. Copy the model name into your `.env` as `GEMINI_MODEL`.

## Key Design Decisions

**Database-driven patterns** — Citation formats and section mappings live in the database, not in code. Adding a new citation format = one INSERT into `citation_patterns`. Adding a new section mapping = one INSERT into `section_mappings`. Zero code changes required.

**UNVERIFIED ≠ REMOVED** — "Not found in IK" does not mean hallucinated. Indian Kanoon has 30M+ documents but not every case is indexed. A citation is only marked REMOVED when the pre-filter also flagged it as suspicious. Clean citations not found in IK are marked UNVERIFIED.

**Parallel IK verification** — All citations are verified simultaneously using Python's `ThreadPoolExecutor`. 7 citations take the same time as 1 citation (~1 second).

**Thread-safe SQLite** — SQLite does not support shared connections across threads. Each verification worker opens its own connection to the database.

**Verification cache** — Every IK result is cached in SQLite. The same citation in a future query costs ₹0.00 and returns instantly.

**Page rule scoped to SCC/SCR/AIR/Cri_LJ only** — SCC OnLine and MANU use document IDs (which can be 6000+), not page numbers. The "impossible page" pre-filter rule only applies to formats that use actual page numbers.

**Session notes** — React state only, intentionally not persisted to the database. Lawyers accumulate research notes within a session without server round-trips. Resets on page refresh by design — sessions are discrete research sessions.

**Model auto-discovery** — If `GEMINI_MODEL` is not set, the system queries the Gemini API for available models and picks the best one automatically. This prevents 404 errors when model names change.

## Troubleshooting

| Problem | Solution |
|---|---|
| `uvicorn: command not found` | Run `pip install uvicorn` |
| `ModuleNotFoundError: fastapi` | Run `pip install -r requirements.txt` |
| Gemini API — model not found (404) | Run `python check_models.py` and update `GEMINI_MODEL` in `.env` |
| Gemini API — quota exceeded (429) | Wait a few minutes (per-minute limit) or until midnight PST (daily limit) |
| IK API — 401 Unauthorized | Re-copy your key from api.indiankanoon.org — check for spaces in `.env` |
| Frontend — blank page | Make sure FastAPI is running on port 8000 before starting React |
| `node_modules` missing | Run `cd frontend && npm install` |
| DB errors on Windows | Delete `db/citations.db` and restart — it auto-recreates |
